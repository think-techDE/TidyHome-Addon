# TidyHome Add-on for Home Assistant

Haushaltsaufgaben organisieren, verteilen und gamifizieren — direkt in Home Assistant.

Inspiriert von [Betidy](https://betidy.io/).

## Features (geplant)

- Haushaltsaufgaben mit Räumen und Intervallen (täglich, wöchentlich, monatlich, jährlich)
- Zuweisung an Familienmitglieder
- Punkte & Bestenliste zur Motivation
- Jahresplan & 14-Tage-Vorschau
- Benachrichtigungen über Home Assistant
- Web-UI direkt im HA-Dashboard (Ingress)

## Installation

1. In Home Assistant: *Einstellungen → Add-ons → Add-on-Store → ⋮ → Benutzerdefinierte Repositories*
2. URL eintragen: `https://git.think-tech.eu/Danny/TidyHome-Addon`
3. TidyHome installieren
